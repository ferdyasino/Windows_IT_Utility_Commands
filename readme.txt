WINDOWS DRIVER TOOLKIT
======================

This toolkit contains three Windows utilities.

1. DRIVER BACKUP
   - Run Export-Windows-Drivers.bat as Administrator.
   - Select a folder where you want to save the backup.
   - Wait for the backup to finish.

2. DRIVER INSTALLATION
   - Run Install-Windows-Drivers.bat as Administrator.
   - Select the folder containing the driver files when prompted.
   - Wait for the installation to finish.
   - Restart the computer if required.

3. HARDWARE INVENTORY
   - Run System-Information-Hardware-Inventory.bat.
   - Wait for the system information to load.
   - Choose where to save the report.
   - Open the saved HTML report in your browser.
   - Use Print or Save as PDF if needed.

IMPORTANT:
- Run driver backup and installation as Administrator.
- Use compatible drivers for your Windows version.
- Always keep a copy of your driver backup.
- Review the results after running each utility.
